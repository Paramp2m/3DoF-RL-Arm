What did not work

The obstacle task is where I was most wrong. I assumed the network could learn the detour on its own. I tried six ways, using a planner as teacher, imitation, then reinforcement fine-tuning. The best reached 89.7% success but hit the box in 11.3% of episodes, where the limit was 5%.

So the policy I kept is not purely learned. A planner proposes a waypoint, the network learns a residual and a safety filter blocks contact. It scores 88.7% with 1.7% collisions. The planner alone scores 89% with 3% collisions, so the learning adds little there. I would rather say so.

The comparisons are early. At 300k steps every learning curve was still rising, so they rank speed, not the end point. With a 1M step budget, plain SAC on the same reach setup got to 88%.

Closed-form inverse kinematics still beats the learned reach policy: 100% and 0 mm against 96% and 5.7 mm. What the policy shows is that the same training code handled five different tasks.

How it is built
and how it was checked

Arm
A three-joint arm of our ownBase yaw, shoulder pitch and elbow pitch, written as an MJCF model for MuJoCo.
Target
A green ball you can moveThe goal is a mocap ball. Move it in code, or drag it with the mouse in the demo window.
Control
25 steps a secondEach step the policy nudges every joint's position setpoint by a small amount.
Observation
What the policy seesSine and cosine of the joint angles, joint speeds, tip position and the target.
Algorithm
SAC with hindsight replayStable-Baselines3, with PPO for the comparison. PyTorch on CPU only, no GPU.
Reward
Every term logged on its ownPrecision, success, settle, joint limits, smoothness and collisions each get a TensorBoard curve.
Configs
Every switch lives in YAMLTask, action mode, reward weights, physics and algorithm. A new experiment is a new config file.
Runs
Each run keeps its receiptsConfig copy, git hash, TensorBoard logs, model, evaluation results and a video.
Evaluation
Fixed goals, separate validation100 evaluation goals. The kept checkpoint is chosen on different validation goals.
Phases
Seven phases, each gatedA phase closed only when a scripted check passed and a written report existed.
Checks
Targets set before the resultsThresholds were fixed in the roadmap. A missed target is reported with evidence, not relaxed.
Hardware
One laptop CPUA Ryzen 7 8845HS. The longest runs took four to five hours.

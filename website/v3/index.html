A three-joint arm in MuJoCo learned to reach a target, hold still on it, follow it around a circle, reach around a box and push a cube across the floor. Each policy is a small neural network trained with reinforcement learning, mostly SAC with hindsight replay, on a laptop CPU. Every number on this page comes from 100 fixed evaluation goals and three training seeds. Where the learned policy is no better than a classical method, or missed its target, the page says so.

What did not work

The network alone

I tried six ways to make the network avoid the box without help: a planner as teacher, imitation, then SAC fine-tuning. The best reached 89.7% success but collided in 11.3% of episodes, against a 5% limit.

What I kept

A planner waypoint, a learned residual and a safety filter: 88.7% success, 1.7% collisions. A planner alone gets 89% and 3%, so the learning adds little there. Closed-form IK also still beats the learned reach policy, 100% to 96%.

How it is built

Three jointsBase yaw, shoulder pitch and elbow pitch, in our own MuJoCo model.
25 steps a secondEach step the policy nudges every joint's position setpoint.
SAC with hindsight replayStable-Baselines3, PPO for comparison, CPU only.
Every switch in YAMLA new experiment is a new config file; each run keeps its config and git hash.
Seven gated phasesEach closed by a scripted check and a written report.

Run it yourself

uv run python scripts/demo.py --headless --steps 2000

Clone the repository and run uv sync first. The headless demo prints the tip-to-target distance in about eight seconds.

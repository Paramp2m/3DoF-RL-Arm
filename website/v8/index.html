Left: the closed-form baseline. Right: the kept obstacle policy.

Classical inverse kinematics beats the learned policy on plain reaching. It needs no training and is exact. The learned policy lands within four points, and the same method also covers hold, track, obstacle and push.

Six network-only attempts at the obstacle task reached 89.7% success but collided 11.3% of the time against a 5% limit. That is reported as a negative result. The kept policy pairs a planner waypoint with a learned residual and a safety filter: 88.7% success, 1.7% collisions.

Run it yourself

Python 3.12 with uv, CPU only. Every behaviour switch lives in a YAML config, and each run keeps its config, git hash and logs.

uv run python scripts/demo.py --headless --steps 2000
